# NFC-thesis
Program to detect communication from radio signal recorded from NFC.

## program usage
Trace files too big for GitHub, so they are not present.
File can be passed to program.

Usage:

    python mfdes_demodulate.py [options]

Options:

    -h --Help               :  Show this message
    -p --Plot               :  Show plots while running
    -t --Trace <trace file> :  Set to decode given file
